# Growth Marketing Lab

Simulador de planejamento de uma campanha para uma marca fictícia. Ajuste o investimento e observe estimativas demonstrativas de alcance, cadastros e oportunidades.

## Funcionalidades

- Controle interativo de orçamento.
- Estimativas calculadas no navegador.
- Premissas visíveis e linguagem sem promessa de resultado.

## Conteúdos relacionados

Gestão Empreendedora, Fundamentos de Marketing e Negócios, Gestão Organizacional, Gestão Estratégica e e-commerce.

## Executar

Abra `index.html` em um navegador. Os valores são hipóteses didáticas, não benchmarks ou recomendações financeiras.
